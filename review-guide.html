STA 9715 · Applied Probability · Baruch

Exam-Night Review: Strategies and Tricks

Chapters 1–5 as a set of moves. Each move says what in the problem should trigger it, what to do, and gives a tiny example with the answer folded underneath.

0. How to attack any problem read this first

  1. Name the random thing. Write "Let \(X\) = …" in words. Half the battle is deciding whether you are counting outcomes, conditioning on information, or describing a random variable.
  2. Find the cue words (table below). They tell you which tool applies.
  3. Look for the easier side. "At least one", "some", "not all" usually mean you should work with the complement. "Expected number of …" means indicators.
  4. Write the formula with symbols first, then plug in numbers. That way you get partial credit even if the arithmetic goes wrong.
  5. Sanity check: probabilities lie in [0, 1], variances are ≥ 0, a PMF sums to 1, and the answer should have about the size you expected.

1. Counting Ch 1

Multiplication principle

Cue A choice made in stages, where each stage has a fixed number of options.

Move Multiply the number of options at each stage. Start with the most restricted stage first (for example "must be even", so fix the last digit first).

$$n_1 \times n_2 \times \cdots \times n_k$$

Tiny example: how many 3-digit numbers with distinct digits are even?

Solution

Fix the last digit. If it is 0: the first digit has 9 options, the middle 8, giving 72. If it is 2, 4, 6 or 8 (4 ways): the first digit can't be 0 or the last digit, so 8 options, and the middle has 8, giving 4·8·8 = 256. Total 328. Trick: split into cases when one restriction affects another.

Order matters or not? Permutations vs. combinations

Cue Ask yourself: "If I swap two of the chosen items, is it a different outcome?" If titles, positions or ranks are involved, order matters. A committee, hand or set: order doesn't matter.

$$P(n,k) = \frac{n!}{(n-k)!}\qquad \binom{n}{k} = \frac{n!}{k!(n-k)!}$$

Tiny example: from 10 people choose (i) a president, VP and secretary; (ii) a 3-person committee.

Solution

(i) \(10\cdot 9\cdot 8 = 720\). (ii) \(\binom{10}{3} = 120 = 720/3!\). Choosing a committee and then giving out titles: \(\binom{10}{3}\cdot 3! = 720\), the same thing.

Arrangements with repeated letters (multinomial)

Cue Arrange objects where some are identical, or split \(n\) people into labelled groups of fixed sizes.

$$\binom{n}{n_1, n_2, \ldots, n_r} = \frac{n!}{n_1!\,n_2!\cdots n_r!}$$

Tiny example: (i) arrangements of LETTER; (ii) 9 people into rooms A, B, C of sizes 4, 3, 2.

Solution

(i) 6 letters with E twice and T twice: \(6!/(2!\,2!) = 180\). (ii) \(9!/(4!\,3!\,2!) = 1260\).

Unlabelled groups: divide by the group-swaps

Cue "Split into teams/pairs" with no names for the teams. Groups of the same size can be swapped without changing the outcome.

Move Count as if the groups were labelled, then divide by \(k!\) for each set of \(k\) equal-size groups.

Tiny example: split 6 people into 3 pairs.

Solution

Labelled: \(6!/(2!2!2!) = 90\). The 3 pairs are interchangeable, so divide by \(3!\): 15. (Check: \(5\cdot3\cdot1 = 15\), since person 1 picks a partner in 5 ways, the next unpaired person in 3 ways, and so on.)

Glue them together / complement for "not together"

Cue "A and B must sit together", or "these books must be adjacent".

Move Treat the group as one block, arrange the blocks, then multiply by the arrangements inside the block. "Not together" = total − together.

Tiny example: 5 people in a row; A and B together? Not together?

Solution

Together: 4 blocks give \(4!\), times \(2!\) inside the block, so 48. Not together: \(120 - 48 = 72\). (Round table with \(n\) people: \((n-1)!\), because rotations are the same.)

Identical items into distinct boxes (stars and bars)

Cue Identical objects (balls, dollars, toys of one kind) distributed to distinct recipients; or the number of non-negative integer solutions of \(x_1+\cdots+x_r = n\).

$$\#\{x_i \ge 0\} = \binom{n+r-1}{r-1}\qquad \#\{x_i \ge 1\} = \binom{n-1}{r-1}$$

Tiny example: 7 identical toys to 3 children; same if every child gets at least one.

Solution

\(\binom{9}{2} = 36\); \(\binom{6}{2} = 15\). Trick for "at least \(m\) each": hand out the minimums first, then use the \(\ge 0\) formula on what's left.

"At least one" by complement

Cue "Contains at least one 7", "at least one ace".

Tiny example: 4-digit PINs (0000–9999) with at least one 7.

Solution

\(10^4 - 9^4 = 3439\). Trap: "choose the 7, then anything" overcounts PINs with two 7s.

Binomial theorem and Vandermonde

Cue "Prove an identity" or "expand"; a committee chosen from two groups.

$$(x+y)^n = \sum_{k=0}^n \binom{n}{k}x^k y^{n-k}\qquad \binom{m+n}{r} = \sum_k \binom{m}{k}\binom{n}{r-k}$$

Story proof: count the same set in two ways. For example, choose \(r\) people from \(m\) women and \(n\) men, split by \(k\) = number of women. Setting \(x=y=1\) gives \(\sum_k\binom nk = 2^n\), the number of subsets.

2. Axioms and equally likely outcomes Ch 2

The basic rules

$$P(A^c) = 1 - P(A)\qquad P(A\cup B) = P(A)+P(B)-P(AB)\qquad A\subset B \Rightarrow P(A)\le P(B)$$

Bounds trick \(\max(0,\,P(A)+P(B)-1) \le P(AB) \le \min(P(A),P(B))\). The union bound is the same thing turned around.

Tiny example: \(P(A)=0.6\), \(P(B)=0.7\). What range can \(P(AB)\) take?

Solution

\([0.3,\ 0.6]\). The low end is when the events overlap as little as possible; the high end is \(A \subset B\).

Inclusion–exclusion

Cue A union of overlapping events, "divisible by 2, 3 or 5", "some suit is missing", "nobody gets their own hat".

$$P(A\cup B\cup C) = \sum P(A_i) - \sum P(A_iA_j) + P(ABC)$$

Move Pick the "bad" events \(A_i\) so that intersections are easy to count; often by symmetry they all have the same probability, which gives \(\sum_k (-1)^{k+1}\binom{n}{k} P(A_1\cdots A_k)\).

Tiny example 1: integers 1–100 divisible by 2, 3 or 5.

Solution

\(50+33+20 - (16+10+6) + 3 = 74\). Use \(\lfloor 100/6\rfloor = 16\), \(\lfloor 100/10\rfloor=10\), \(\lfloor 100/15\rfloor=6\), \(\lfloor 100/30\rfloor = 3\).

Tiny example 2 (matching): 4 letters randomly placed into 4 envelopes. P(no letter in its own envelope)?

Solution

\(A_i\) = letter \(i\) matches. \(P(\text{some match}) = \sum_{k=1}^4 (-1)^{k+1}\binom4k\frac{(4-k)!}{4!} = 1 - \tfrac12 + \tfrac16 - \tfrac1{24}\). So \(P(\text{none}) = \sum_{k=0}^4 \frac{(-1)^k}{k!} = \frac{3}{8}\), which tends to \(e^{-1}\approx 0.368\) as \(n\) grows.

Tiny example 3: P(a 5-card hand is missing at least one suit)?

Solution

\(\dfrac{4\binom{39}{5} - 6\binom{26}{5} + 4\binom{13}{5}}{\binom{52}{5}}\). Missing a given suit means all 5 cards come from the other 39.

Equally likely: numerator and denominator must match

Move \(P(E) = |E|/|S|\). Decide ordered or unordered once and use the same choice for both. Unordered with \(\binom{\cdot}{\cdot}\) is usually easier for hands and committees.

Tiny example: 2 cards drawn. P(both aces)?

Solution

Unordered: \(\binom42/\binom{52}2 = 6/1326 = 1/221\). Ordered: \(\frac{4\cdot3}{52\cdot51}\), the same answer.

Tiny example: birthday problem with 23 people.

Solution

\(P(\text{all different}) = \frac{365\cdot364\cdots343}{365^{23}} \approx 0.4927\), so P(a shared birthday) ≈ 0.5073. A complement again.

3. Conditioning, Bayes, independence Ch 3

Conditional probability and the multiplication rule

$$P(A\mid B) = \frac{P(AB)}{P(B)}\qquad P(A_1A_2\cdots A_n) = P(A_1)P(A_2\mid A_1)P(A_3\mid A_1A_2)\cdots$$

Cue Sequential draws without replacement: chain the conditionals instead of counting.

Trick Conditioning on \(B\) shrinks the sample space to \(B\). With equally likely outcomes, \(P(A\mid B) = |AB|/|B|\).

Tiny example: two children, at least one is a girl. P(both girls)?

Solution

Reduced space {GG, GB, BG}, so the answer is 1/3, not 1/2. (If you're told the eldest is a girl, it is 1/2.)

Law of total probability + Bayes (the tree)

Cue Hidden "type" (diseased or healthy, coin A or coin B, supplier 1 or 2) followed by an observation; asked about the type given the observation.

$$P(B_j\mid A) = \frac{P(A\mid B_j)P(B_j)}{\sum_i P(A\mid B_i)P(B_i)}$$

Move Draw the tree: prior on the first branch, likelihood on the second. Answer = (the path you want) / (sum of all paths that produce the observation).

Tiny example: 1% have the disease; the test catches 95% of them and false-alarms on 5% of healthy people. P(disease | +)?

Solution

\(\dfrac{0.01(0.95)}{0.01(0.95)+0.99(0.05)} = \dfrac{0.0095}{0.059} = 0.1610\). A low prior keeps the posterior low.

Odds form and conditional independence (repeated evidence)

Cue "Tested twice", "results independent given the true status", "two scans".

$$\frac{P(D\mid \text{data})}{P(D^c\mid \text{data})} = \frac{P(D)}{P(D^c)}\times\frac{P(\text{data}\mid D)}{P(\text{data}\mid D^c)}$$

Move Given the type, multiply the likelihoods: \(P(++\mid D) = 0.95^2\). Trap: the two results are not unconditionally independent, because they both depend on \(D\). Find \(P(++)\) by total probability, not by \(P(+)^2\).

Tiny example: same test, two independent positives. P(disease)?

Solution

\(\dfrac{0.01(0.95)^2}{0.01(0.95)^2+0.99(0.05)^2} = \dfrac{0.009025}{0.0115} = 0.7848\). Odds: prior 1/99 times likelihood ratio \(19^2 = 361\) gives \(361/99\), so the probability is \(361/460\).

Trick To predict the next observation given past data, update first, then use total probability with the posterior weights: \(P(\text{next}+\mid ++) = \sum_i P(+\mid B_i)P(B_i\mid ++)\).

Independence

$$A\perp B \iff P(AB) = P(A)P(B)$$

Check Prove it with numbers; never assume it. If \(A \perp B\) then \(A^c \perp B\) and so on. Three events need all pairs and \(P(ABC)=P(A)P(B)P(C)\). Disjoint events with positive probability are never independent.

Systems Series (all must work): \(\prod p_i\). Parallel (at least one works): \(1-\prod(1-p_i)\). Mixed: collapse the inner blocks first.

Tiny example: components with reliability 0.9 and 0.8 in parallel, then that block in series with a 0.95 component.

Solution

Parallel block: \(1 - 0.1(0.2) = 0.98\). System: \(0.98(0.95) = 0.931\).

First-step conditioning (games that repeat)

Cue "Alternate until someone wins", "repeat until…".

Move Condition on what happens in the first round. If nothing is decided, the game restarts, so you get \(p_A = (\text{win now}) + (\text{nothing happens})\,p_A\).

Tiny example: Ann hits with prob 0.4, then Bea with 0.3, alternating, Ann first. P(Ann wins)?

Solution

\(p = 0.4 + (0.6)(0.7)p \Rightarrow p = 0.4/0.58 = 20/29 \approx 0.6897\).

4. Discrete random variables Ch 4

PMF and CDF

Facts \(F(x) = P(X\le x)\) is non-decreasing and right-continuous. \(P(X = a) = F(a) - F(a^-)\), the jump. \(P(a < X \le b) = F(b)-F(a)\). \(P(X < b) = F(b^-)\).

Max/min trick \(P(\max \le k) = P(\text{all} \le k)\), and \(P(\min > k) = P(\text{all} > k)\). Then get the PMF by differencing: \(P(M=k) = P(M\le k)-P(M\le k-1)\).

Tiny example: \(M\) = max of two fair dice. PMF?

Solution

\(P(M\le k) = (k/6)^2\), so \(P(M=k) = \dfrac{k^2-(k-1)^2}{36} = \dfrac{2k-1}{36}\).

Expectation, LOTUS, variance

$$E[X]=\sum x\,p(x)\qquad E[g(X)] = \sum g(x)p(x)\qquad \text{Var}(X) = E[X^2]-(E[X])^2$$ $$E[aX+b] = aE[X]+b\qquad \text{Var}(aX+b) = a^2\,\text{Var}(X)$$

Trap \(E[g(X)] \ne g(E[X])\) in general (for example \(E[1/X]\), \(E[X^2]\)). Use LOTUS. The shift \(b\) drops out of the variance.

Cost/profit Write profit as a function of \(X\), then take \(E\). For "how many to stock", compare \(E[\text{profit}]\) at \(s\) and \(s+1\): stock one more while the extra unit's expected gain is positive.

Fair game "Fair" means \(E[\text{net winnings}] = 0\). Solve for the unknown payout.

Tail sum For \(X\in\{0,1,2,\ldots\}\): \(E[X] = \sum_{k\ge1}P(X\ge k)\).

Tiny example: \(X\) takes values 0, 1, 2 with probabilities 0.5, 0.3, 0.2. Find \(E[X]\), \(\text{Var}(X)\), \(\text{Var}(3-2X)\).

Solution

\(E[X] = 0.3+0.4 = 0.7\); \(E[X^2] = 0.3 + 0.8 = 1.1\); \(\text{Var} = 1.1-0.49 = 0.61\); \(\text{Var}(3-2X) = 4(0.61) = 2.44\).

Binomial\((n,p)\)

Cue Fixed number of independent trials, the same \(p\) each time, counting successes.

$$P(X=k) = \binom nk p^k(1-p)^{n-k}\quad E=np\quad \text{Var}=np(1-p)\quad E[s^X] = (1-p+ps)^n$$

Tricks "At least 1" = \(1-(1-p)^n\). Given the mean and variance: \(1-p = \text{Var}/E\), then \(n = E/p\). Find the smallest \(n\) with \(P(\ge1)\ge 0.95\): \(n \ge \ln 0.05/\ln(1-p)\).

Tiny example: \(X\sim\text{Bin}(10, 0.3)\), \(P(X=2)\)? A binomial has mean 6 and variance 2.4; find \(n, p\).

Solution

\(45(0.09)(0.7)^8 = 0.2335\). And \(1-p = 0.4\), so \(p = 0.6\) and \(n = 10\).

Poisson\((\lambda)\): approximation, paradigm, process

Cue Many independent rare chances (typos, defects, arrivals); "on average λ per unit"; Bin(\(n,p\)) with \(n\) large and \(p\) small.

$$P(X=k)=e^{-\lambda}\frac{\lambda^k}{k!}\qquad E=\text{Var}=\lambda\qquad E[s^X]=e^{\lambda(s-1)}$$

Moves

  • Approximation: \(\text{Bin}(n,p)\approx\text{Poi}(np)\).
  • Process: the count in a window of length \(t\) is \(\text{Poi}(\lambda t)\). Rescale λ to the window: 2 per page means 6 on 3 pages. Disjoint windows are independent.
  • Thinning: if each event is independently "type A" with prob \(q\), type-A events form a Poisson process with rate \(\lambda q\).
  • "\(P(X=1) = P(X=2)\)": set the PMFs equal and solve for λ (here λ = 2).

Tiny example: 2 typos per page on average. P(a page is clean)? P(at most 1 typo in 3 pages)?

Solution

\(e^{-2} = 0.1353\). Over 3 pages the count is Poi(6): \(e^{-6}(1+6) = 0.0174\).

Geometric and negative binomial

Cue "Number of trials until the first (or \(r\)-th) success".

$$\text{Geo: } P(X=k) = (1-p)^{k-1}p,\quad E=\tfrac1p,\quad \text{Var}=\tfrac{1-p}{p^2},\quad P(X>k) = (1-p)^k$$ $$\text{NegBin: } P(X=k) = \binom{k-1}{r-1}p^r(1-p)^{k-r},\quad E=\tfrac rp,\quad \text{Var}=\tfrac{r(1-p)}{p^2}$$

Why \(\binom{k-1}{r-1}\) The \(k\)-th trial must be the \(r\)-th success, so choose where the other \(r-1\) successes fall among the first \(k-1\) trials.

Memoryless \(P(X>m+n\mid X>m) = P(X>n)\): past failures don't matter.

Tiny example: \(p = 0.3\). P(first success on trial 4)? With \(p=0.5\), P(3rd success on trial 5)?

Solution

\(0.7^3(0.3) = 0.1029\). \(\binom42(0.5)^5 = 6/32 = 0.1875\).

Hypergeometric

Cue Sample \(n\) without replacement from \(N\) items, \(m\) of which are "special".

$$P(X=k)=\frac{\binom mk\binom{N-m}{n-k}}{\binom Nn}\qquad E = n\frac mN\qquad \text{Var} = n\frac mN\Big(1-\frac mN\Big)\frac{N-n}{N-1}$$

The mean is the same as the binomial's; the variance is shrunk by the finite-population factor \(\frac{N-n}{N-1}\).

Tiny example: 20 items, 5 defective; sample 5. P(exactly 2 defective)? Expected number defective?

Solution

\(\binom52\binom{15}3/\binom{20}5 = 0.2935\); \(E = 5(5/20) = 1.25\).

Indicators: the biggest trick in the course

Cue "Expected number of …" where computing the full distribution is awful (matches, distinct faces, pairs, empty boxes, aces in the first 10 cards).

Move Write \(X = I_1 + \cdots + I_n\) with \(I_j = 1\) if thing \(j\) happens. Then \(E[X] = \sum P(\text{thing } j)\). No independence needed.

Tiny example: roll 6 dice. Expected number of distinct faces? Expected number of matches when \(n\) letters are put in \(n\) envelopes?

Solution

\(I_j\) = face \(j\) appears: \(P = 1-(5/6)^6\), so \(E = 6(1-(5/6)^6) = 3.9906\). Matches: each letter matches with prob \(1/n\), so \(E = n\cdot\frac1n = 1\).

Coupon collector The time to collect all \(n\) types is a sum of geometrics: \(E = n\left(\frac1n+\frac1{n-1}+\cdots+1\right)\).

5. Continuous random variables Ch 5

Density recipe: c, probabilities, mean, variance

$$\int f = 1\qquad P(a<X<b) = \int_a^b f\qquad F'(x) = f(x)\qquad E[g(X)] = \int g(x)f(x)\,dx$$

Facts \(P(X = a) = 0\), so \(<\) and \(\le\) don't matter. A density can exceed 1. The median \(m\) solves \(F(m) = 1/2\).

Trick For \(X \ge 0\): \(E[X] = \int_0^\infty P(X>x)\,dx\). For gamma-shaped integrals, \(\int_0^\infty x^n e^{-ax}dx = n!/a^{n+1}\).

Tiny example: \(f(x) = cx^2\) on \((0,3)\). Find \(c\), \(E[X]\), \(\text{Var}(X)\).

Solution

\(c\cdot 9 = 1 \Rightarrow c = 1/9\). \(E[X] = \int_0^3 x^3/9 = 81/36 = 9/4\). \(E[X^2] = \int_0^3 x^4/9 = 27/5\). \(\text{Var} = 27/5 - 81/16 = 27/80\).

Mixed distributions (jumps + slopes)

Cue A CDF that jumps at some points and rises smoothly elsewhere ("wait 0 if the light is green", "claim is 0 with prob 0.3").

Move Point masses = jump sizes. Continuous part = \(F'(x)\) where it's smooth. Check that everything adds to 1.

$$E[X] = \sum_{\text{jumps}} a\cdot P(X=a) + \int x\,F'(x)\,dx$$

Tiny example: \(F(x) = 0\) for \(x<0\); \(0.2+0.4x\) for \(0\le x<1\); \(1\) for \(x\ge1\). Find the point masses and \(E[X]\).

Solution

Jump at 0 of size 0.2; jump at 1 of size \(1 - 0.6 = 0.4\); density 0.4 on \((0,1)\) (total 0.4, and 0.2 + 0.4 + 0.4 = 1 ✓). \(E = 0 + 1(0.4) + \int_0^1 0.4x\,dx = 0.6\). Check with the tail formula: \(\int_0^1(0.8-0.4x)dx = 0.6\) ✓.

Uniform\((a,b)\)

$$f = \frac1{b-a}\qquad P = \frac{\text{length}}{b-a}\qquad E = \frac{a+b}2\qquad \text{Var} = \frac{(b-a)^2}{12}$$

Trick Conditioned on landing in a sub-interval, it is still uniform on that sub-interval. A "uniform point in a region" means probability = area ratio.

Normal: standardise everything

$$Z = \frac{X-\mu}{\sigma}\qquad P(X\le x) = \Phi\!\left(\frac{x-\mu}\sigma\right)\qquad \Phi(-z) = 1-\Phi(z)$$

Moves

  • Forward: value → \(z\) → table.
  • Reverse (percentile): \(x = \mu + z\sigma\), for example the 95th percentile is \(\mu + 1.645\sigma\).
  • Two percentiles given: two equations \(x_i = \mu + z_i\sigma\); subtract to get \(\sigma\).
  • \(aX+b\) is normal with mean \(a\mu+b\) and SD \(|a|\sigma\).
  • "Within \(k\)" means \(P(|X-\mu|<k) = 2\Phi(k/\sigma)-1\).
  • Normal then binomial: first get \(p = P(\text{one item is out of spec})\), then count items with Bin(\(n, p\)).

Tiny example: IQ ~ N(100, 15²). P(IQ > 130)? The 90th percentile? (\(\Phi(2) = 0.9772\), \(\Phi(1.28) = 0.8997\).)

Solution

\(z = 2\), so \(1 - 0.9772 = 0.0228\). 90th percentile ≈ \(100 + 1.28(15) = 119.2\).

DeMoivre–Laplace: normal approximation to the binomial

Cue Binomial with large \(n\); the check is \(np(1-p)\ge 10\). (If \(p\) is tiny, use Poisson instead.)

Move Use \(\mu = np\), \(\sigma = \sqrt{np(1-p)}\), and the continuity correction: widen to include the whole bar of each integer you want.

BinomialNormal
\(P(X = k)\)\(P(k-0.5 < Y < k+0.5)\)
\(P(X \le k)\)\(P(Y < k+0.5)\)
\(P(X < k)\)\(P(Y < k-0.5)\)
\(P(X \ge k)\)\(P(Y > k-0.5)\)
\(P(X > k)\)\(P(Y > k+0.5)\)

Tiny example: 100 fair coin flips. P(at least 60 heads)? (\(\Phi(1.9) = 0.9713\).)

Solution

\(\mu = 50\), \(\sigma = 5\), \(np(1-p) = 25 \ge 10\) ✓. \(P(Y>59.5) = 1-\Phi(1.9) = 0.0287\) (exact: 0.0284).

Required \(n\) "How many must we sell so that P(at least 100) ≥ 0.95": set \(\frac{99.5 - np}{\sqrt{np(1-p)}} = -1.645\) and solve the quadratic in \(\sqrt n\), or test candidate values of \(n\).

Exponential\((\lambda)\)

$$f = \lambda e^{-\lambda x}\quad P(X>t) = e^{-\lambda t}\quad E = \frac1\lambda\quad \text{Var} = \frac1{\lambda^2}$$

Moves

  • Read the parameter carefully: "mean 10 hours" means \(\lambda = 1/10\).
  • Memoryless: \(P(X>s+t\mid X>s) = P(X>t)\). A used part is as good as new.
  • Poisson link: in a Poisson process with rate λ, the time to the next event is Exp(λ), and \(P(T>t) = P(\text{0 events in } [0,t]) = e^{-\lambda t}\).
  • Min of independent exponentials is Exp(\(\lambda_1+\cdots+\lambda_n\)) (series system). Max: \(P(\max\le t) = \prod(1-e^{-\lambda_it})\) (parallel system).
  • Deductible \(d\): \(E[(X-d)^+] = P(X>d)\cdot\frac1\lambda = e^{-\lambda d}/\lambda\), because of memorylessness.
  • Rounding up: \(\lceil X\rceil\) is geometric with \(p = 1-e^{-\lambda}\).

Tiny example: bulbs last Exp with mean 10 h. A bulb has lasted 5 h. P(it lasts past 15 h)?

Solution

Memoryless: \(P(X>10) = e^{-1} = 0.3679\).

Hazard (failure) rate

$$\lambda(t) = \frac{f(t)}{1-F(t)}\qquad 1-F(t) = \exp\!\Big(-\int_0^t\lambda(s)\,ds\Big)\qquad f = \lambda(t)\,(1-F(t))$$

A constant hazard means exponential. An increasing hazard means it wears out. Piecewise hazards: add up the integrals piece by piece.

Tiny example: \(\lambda(t) = 0.1t\). P(survive past 2)?

Solution

\(\int_0^2 0.1s\,ds = 0.2\), so \(e^{-0.2} = 0.8187\).

Distribution of \(Y = g(X)\)

CDF method (always works)

  1. Write \(F_Y(y) = P(g(X)\le y)\).
  2. Solve the inequality for \(X\). Flip it if \(g\) is decreasing; get two pieces if \(g\) isn't one-to-one (for example \(X^2\) or \(|X|\)).
  3. Express the result with \(F_X\), then differentiate to get \(f_Y\). State the range of \(y\).

Thm 5.7.1 (monotone \(g\))

$$f_Y(y) = f_X\big(g^{-1}(y)\big)\,\Big|\tfrac{d}{dy}g^{-1}(y)\Big|$$

Tiny example 1: \(U\sim\text{Unif}(0,1)\), \(Y = -2\ln U\).

Solution

\(P(Y\le y) = P(\ln U \ge -y/2) = P(U\ge e^{-y/2}) = 1 - e^{-y/2}\) for \(y>0\): Exp with \(\lambda = 1/2\).

Tiny example 2: \(X\sim\text{Unif}(-1,1)\), \(Y = X^2\).

Solution

\(P(Y\le y) = P(-\sqrt y\le X\le\sqrt y) = \sqrt y\) for \(0<y<1\), so \(f_Y = \frac{1}{2\sqrt y}\).

Shortcut If they only ask for \(E[Y]\), skip all this: \(E[g(X)] = \int g(x)f(x)\,dx\).

Traps that cost points last look

  • Mixing ordered and unordered counts in the same fraction.
  • "At least one" counted directly ("pick one, then anything") gives a double count. Use the complement.
  • Writing \(P(A\mid B)\) when the question asks for \(P(B\mid A)\). Say aloud what is given.
  • Assuming repeated tests are unconditionally independent. They are independent only given the hidden state.
  • Forgetting to rescale the Poisson rate to the window, or confusing a rate with a mean for the exponential (λ = 1/mean).
  • Geometric conventions: this course counts trials (\(k\ge1\)), so \(P(X>k) = (1-p)^k\).
  • Normal approximation without the continuity correction, or applying it in the wrong direction.
  • \(\text{Var}(aX+b) = a^2\text{Var}(X)\), not \(a\,\text{Var}\); and the \(b\) disappears.
  • A mixed CDF: forgetting the point masses when computing \(E[X]\).
  • \(Y = g(X)\): forgetting the support of \(Y\), or the absolute value of the derivative, or the second branch when \(g\) isn't one-to-one.
  • \(E[g(X)] \ne g(E[X])\).
